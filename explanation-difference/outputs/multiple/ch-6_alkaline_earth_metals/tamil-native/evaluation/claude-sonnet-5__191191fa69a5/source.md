# காரமண் உலோகங்கள் (Alkaline Earth Metals)

## அறிமுகம்

கால அட்டவணையின் **2வது தொகுதியில் (Group 2)** உள்ள தனிமங்களை காரமண் உலோகங்கள் என்று அழைக்கிறோம். இவை:

- பெரிலியம் (Be)
- மெக்னீசியம் (Mg)
- கால்சியம் (Ca)
- ஸ்ட்ரோன்சியம் (Sr)
- பேரியம் (Ba)
- ரேடியம் (Ra)

## பெயர் வந்த காரணம்

இவற்றின் ஆக்சைடுகள் (oxides) நீரில் கரைந்து **காரத் தன்மை** (alkaline) கொண்ட கரைசலைத் தருகின்றன. மேலும், இவை பூமியில் **கனிமங்களாக** (earth-like minerals) அதிகம் காணப்படுவதால் "மண்" (earth) என்ற பெயர் சேர்க்கப்பட்டுள்ளது.

## எலக்ட்ரான் அமைப்பு

இவற்றின் வெளிக்கூட்டில் **2 எலக்ட்ரான்கள்** (ns²) உள்ளன. எடுத்துக்காட்டாக:
- Mg: 2, 8, 2
- Ca: 2, 8, 8, 2

## முக்கிய பண்புகள்

| பண்பு | விளக்கம் |
|-------|----------|
| **இணைதிறன்** | +2 (இரண்டு எலக்ட்ரான்களையும் இழந்து நிலைப்படைகிறது) |
| **வினைத்திறன்** | தொகுதி 1 உலோகங்களை விட குறைவு, ஆனால் நல்ல வினைத்திறன் உண்டு |
| **அடர்த்தி** | ஒப்பீட்டளவில் அதிகம் (தொகுதி 1 உலோகங்களை விட) |
| **உருகுநிலை** | அதிகம் |
| **நிறம்** | வெள்ளி-வெண்மை (silvery-white) நிற உலோகங்கள் |

## முக்கிய வேதி வினைகள்

**1. நீருடன் வினை:**
$$Ca + 2H_2O \rightarrow Ca(OH)_2 + H_2$$

**2. ஆக்ஸிஜனுடன் வினை:**
$$2Mg + O_2 \rightarrow 2MgO$$

**3. அமிலத்துடன் வினை:**
$$Mg + 2HCl \rightarrow MgCl_2 + H_2$$

## பயன்பாடுகள்

- **மெக்னீசியம்**: விமான உற்பத்தி, மருந்துகளில் (மெக்னீசியம் ஹைட்ராக்சைடு - அஜீரண மருந்து)
- **கால்சியம்**: எலும்பு, பல் வளர்ச்சிக்கு அவசியம்; சிமெண்ட், சுண்ணாம்பு தயாரிப்பில் பயன்படுகிறது
- **பேரியம்**: X-ray பரிசோதனையில் "பேரியம் மீல்" பயன்படுத்தப்படுகிறது

## எளிய நினைவு கூறல்

**"Be Mg Ca Sr Ba Ra"** - இதை "பெருமால் காணும் ஸ்ரீ பாராயணம்" போன்ற தமிழ் வாக்கியமாக நினைவில் வைத்துக்கொள்ளலாம்!
