# Oxidation - Reduction Reactions (Redox Reactions)

Hello! Let us understand this important topic simply.

## 1. Basic Definition

**Oxidation** and **Reduction** always happen together. One does not happen without the other - that is why we call this **"Redox"** (Reduction + Oxidation).

## 2. Three Types of Definitions

### a) Old method (Based on oxygen)
| | Oxidation | Reduction |
|---|---|---|
| Oxygen | is added | is removed |
| Hydrogen | is removed | is added |

**Example:** 
$$2Mg + O_2 \rightarrow 2MgO$$
Here Mg undergoes oxidation (O is added)

### b) Based on electrons (Important!)

- **Oxidation** = **Loss** of electrons (Loss of electrons)
- **Reduction** = **Gain** of electrons (Gain of electrons)

**Easy way to remember - "OIL RIG"**
- **O**xidation **I**s **L**oss (Oxidation = loss)
- **R**eduction **I**s **G**ain (Reduction = gain)

**Example:**
$$Zn \rightarrow Zn^{2+} + 2e^-$$ (Zn loses electrons → Oxidation)

$$Cu^{2+} + 2e^- \rightarrow Cu$$ (Cu gains electrons → Reduction)

### c) Based on oxidation number
- Oxidation = oxidation number **increases**
- Reduction = oxidation number **decreases**

## 3. Full Example

$$Zn + CuSO_4 \rightarrow ZnSO_4 + Cu$$

| Metal | Change | Oxidation number | Process |
|---|---|---|---|
| Zn | Zn → Zn²⁺ | 0 → +2 | Oxidation |
| Cu | Cu²⁺ → Cu | +2 → 0 | Reduction |

## 4. Key Terms

- **Oxidizing agent (Oxidizing agent)**: The substance that oxidizes another substance (itself undergoes reduction)
- **Reducing agent (Reducing agent)**: The substance that reduces another substance (itself undergoes oxidation)

In the example above:
- Zn → Reducing agent (reduces Cu)
- CuSO₄ → Oxidizing agent (oxidizes Zn)

## 5. Examples in Daily Life

1. **Rusting of iron**: $4Fe + 3O_2 \rightarrow 2Fe_2O_3$
2. **Respiration**: Glucose undergoes oxidation and gives energy
3. **Batteries (Batteries)**: Electricity is produced through redox reactions only
