```text
**Mg + CuSO₄ → MgSO₄ + Cu** বিক্রিয়াটা দেখি:

- ম্যাগনেসিয়াম (Mg) তার ২টি ইলেকট্রন হারিয়ে Mg²⁺ হয়ে যায় → এটা **জারিত** হলো
- কপার আয়ন (Cu²⁺) সেই ইলেকট্রন গ্রহণ করে Cu ধাতুতে পরিণত হয় → এটা **বিজারিত** হলো

$$Mg \rightarrow Mg^{2+} + 2e^-$$ (জারণ)
$$Cu^{2+} + 2e^- \rightarrow Cu$$ (বিজারণ)
```
