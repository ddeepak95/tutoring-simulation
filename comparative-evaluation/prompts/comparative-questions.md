# Comparative questions for instructional explanations

## Purpose and source basis

Compare two tutor responses, A and B, on the same learning topic. The questions below adapt the two Kulgemeyer papers in `conversation-evaluation/ref` to the portal's existing comparative format: a stable `key`, an item `label`, a comparative question (`description`), judging `guidance`, and a `subsequent_only` flag. These are proposed operational questions, not a validated scale published in either paper.

Source references used below:

- **S1:** Kulgemeyer, *Towards a framework for effective instructional explanations in science teaching*, DOI: 10.1080/03057267.2018.1598054. The local filename says 2018; the PDF records online publication on 15 April 2019. PDF pages 7–9 describe the seven core ideas and the explanation–diagnosis–adaptation–task process; PDF pages 12–19 discuss the supporting factors.
- **S2:** Kulgemeyer (2020), *A Framework of Effective Science Explanation Videos Informed by Criteria for Instructional Explanations*, *Research in Science Education*, 50, 2441–2462, DOI: 10.1007/s11165-018-9787-7. PDF pages 6–9 discuss the criteria; Table 2 on PDF page 10 (journal page 2450) lists fourteen features under seven factors.

The questions use criteria that can be assessed in written tutoring. Video production features such as audio delivery, camera work, or animation quality are excluded. Interactive diagnosis and adaptation draw primarily on S1; S2 explicitly distinguishes a prerecorded video's fixed audience adaptation from interactive refinement.

## Instructions for the annotator

For each question, choose **A is better**, **B is better**, or **Tie / equally good**. Judge that criterion independently; do not pick an overall winner. A tie means neither response is meaningfully better on the criterion, including when both are weak or neither uses an optional feature. Optional notes may explain the difference or the reason for a tie.

Evaluate the current tutor responses using the preceding conversation and any supplied learner profile or learning goal. Use each candidate's own learner context: differing learner replies can create different opportunities to respond. Do not assume knowledge, interests, or misconceptions from the conversation language. Assess language and direct address from the original wording; translations support interpretation.

Compare instructional usefulness, not the number of features. More examples, longer responses, more formulas, or more summaries do not automatically make an explanation better. An appropriate omission can be preferable to an unnecessary addition. Do not infer demonstrated learning or transfer solely from how an explanation is written.

If a conditional feature is absent from both responses and there is no relevant opportunity, choose Tie for the three-choice portal workflow and optionally note that the criterion was not applicable. If context is insufficient, flag it in notes or for review; do not interpret that tie as evidence that the explanations have equal quality. Automated evaluation using the existing pipeline may instead return `not_applicable` or `insufficient_evidence` as its schema permits.

## Questions

All items use the same response options: **A is better / B is better / Tie / equally good**. The **Timing** column supplies `subsequent_only`: **All turns** means `false`; **Subsequent turns** means `true` and excludes the initial tutor response. These timing choices are adaptations for the portal, not rules stated by the papers.

## Relationship to the current questions

This combined set contains **9 initial-turn questions** and **11 subsequent-turn questions**. It reduces the earlier 16-question draft through three combinations:

- **Fit for the Learner:** learner level, language, and mathematics.
- **Usefulness of Explanatory Aids:** examples, analogies/models, and representations.
- **Focus and Amount of Information:** topic relevance and information load.

The combined items use new keys (`learner_fit`, `explanatory_aids_usefulness`, and `focus_and_information_load`) because their meaning is broader than any one former item. Results should not be treated as interchangeable with the former individual ratings. Annotators should consider the listed aspects together and use notes to explain meaningful tradeoffs.

Principle focus, learning-goal structure, summarization, relevance to the learner, direct address, opportunities to demonstrate understanding, coherence, and responsiveness remain separate. Focus on the learning topic concerns what information belongs in the explanation; relevance to the learner concerns why the topic matters to that learner. Opportunities to demonstrate understanding assess what the tutor invites the learner to do; responsiveness assesses how the tutor uses learner contributions that have already occurred.

`conversational_naturalness` is narrowed to direct address and engagement, so its revised results should not be treated as identical to earlier naturalness judgments. **Positivity of Tone** is not included in this paper-based set: warmth, praise, and empathy are not distinct criteria in these two frameworks. It can remain a separate study-specific question with a separate justification. Scientific correctness should likewise remain a separate error check; S2's experimental comparison held scientific correctness constant. Incorrect examples or reasoning still affect the usefulness of the corresponding explanation feature.

The portal uses this combined set for newly created comparisons. Existing comparison assignments retain their stored question snapshots and completion requirements; Annotate ratings are separate. Optional tool-specific aspects do not require an explanatory aid when none is useful. The current three-choice workflow requires a recorded choice for each active question.

For whole-conversation evaluation, use the same criteria across the full exchange and disregard the turn-display flags. Assess diagnosis, adaptation, and follow-up tasks where opportunities occur rather than requiring them in every tutor message. Claims of improved learning would require learner outcome evidence beyond a preference judgment.
